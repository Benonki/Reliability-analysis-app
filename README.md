# Reliability analysis App

A Python-based application for calculating and analyzing reliability indicators of non-repairable systems using exponential and Erlang distributions, helping users evaluate failure probability, reliability, failure density, failure rate, mean time to failure, and variance.

## ⚙️ Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Benonki/Reliability-analysis-app.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
   - If you update the project, refresh `requirements.txt`:
     ```bash
     pip freeze > requirements.txt
      ```

## 🚀 Running the App

1. Start the desktop app:
   ```bash
   python main.py
   ```
